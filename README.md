# Калькулятор СЛАУ (Систем Линейных Алгебраических Уравнений)

Десктопное приложение с графическим интерфейсом на **Tkinter**, предназначенное для аналитического решения систем линейных алгебраических уравнений (СЛАУ) тремя классическими методами: **методом Гаусса**, **методом Крамера** и **матричным методом**.

Проект выполнен **на чистом Python без использования сторонних математических библиотек (NumPy, SciPy и др.)**, с акцентом на самостоятельную алгоритмическую реализацию и подробный пошаговый вывод каждого этапа решения.

---

## 📌 Основные возможности

* **Три метода решения**:
  * **Метод Гаусса** (метод последовательного исключения неизвестных) — универсальный метод для систем любого размера ($m \times n$).
  * **Метод Крамера** — решение через главный и вспомогательные определители.
  * **Матричный метод** — нахождение обратной матрицы через алгебраические дополнения ($X = A^{-1} \cdot B$).
* **Математическая строгость и валидация**:
  * Автоматическая проверка размерности: для прямоугольных систем ($m \neq n$) блокируются методы Крамера и матричный, выводится теоретическое обоснование и запускается метод Гаусса.
  * Проверка вырожденности квадратной матрицы ($\det(A) = 0$).
  * Полный анализ совместности по теореме Кронекера–Капелли (определение несовместности и систем с бесконечным множеством решений).
* **Подробное пошаговое протоколирование**:
  * Вывод промежуточных матриц с выравниванием по столбцам.
  * Запись формул элементарных преобразований строк.
  * Отображение матриц алгебраических дополнений, транспонированных и обратных матриц.
* **Удобный графический интерфейс**:
  * Динамическая генерация сетки ввода коэффициентов $[A \mid B]$ под любые размеры $m \times n$.
  * Встроенный скроллинг (Canvas + Scrollbars) для работы с матрицами больших порядков.
  * Поддержка как точки, так и запятой при вводе вещественных чисел (`1.5` и `1,5`).
  * Быстрые пресеты для демонстрации типовых случаев.
  * Многовкладочный просмотр результатов (`ttk.Notebook`) с возможностью копирования текста.

## 📐 Математические методы и условия их применимости

| Метод | Требования к системе | Ограничения | Результат при вырожденности / несовместности |
| :--- | :--- | :--- | :--- |
| **Метод Гаусса** | Любая ($m \times n$) | Нет | Находит единственное решение, сообщает о бесконечном множестве решений или несовместности |
| **Метод Крамера** | Квадратная ($m = n$) | $\det(A) \neq 0$ | Неприменим при $m \neq n$ и при $\Delta = 0$ |
| **Матричный метод** | Квадратная ($m = n$) | $\det(A) \neq 0$ | Неприменим при $m \neq n$ и при $\det(A) = 0$ ($A^{-1}$ не существует) |

### 1. Метод Гаусса
1. Составляется расширенная матрица $[A \mid B]$.
2. **Прямой ход**: приведение матрицы к верхнетреугольному (ступенчатому) виду с использованием частичного выбора главного элемента по столбцу (partial pivoting).
3. **Анализ совместности**: если в ступенчатой матрице появляется строка вида $[0 \; 0 \; \dots \; 0 \mid b_i]$ при $b_i \neq 0$, система объявляется **несовместной** (не имеет решений).
4. Если $\mathrm{rank}(A) < n$, система объявляется **неопределенной** (имеет бесконечно много решений).
5. **Обратный ход**: при $\mathrm{rank}(A) = n$ последовательно находятся неизвестные $x_n, x_{n-1}, \dots, x_1$.

### 2. Метод Крамера
1. Вычисляется главный определитель матрицы коэффициентов $\Delta = \det(A)$.
2. Если $\Delta = 0$, метод неприменим.
3. Для каждой переменной $j = 1 \dots n$ строится матрица $A_j$, в которой $j$-й столбец заменяется на вектор свободных членов $B$.
4. Вычисляются определители $\Delta_j = \det(A_j)$.
5. Находятся неизвестные: $x_j = \frac{\Delta_j}{\Delta}$.

### 3. Матричный метод
1. Вычисляется определитель $\det(A)$. Если $\det(A) = 0$, обратная матрица не существует.
2. Вычисляются миноры $M_{ij}$ и матрица алгебраических дополнений $C_{ij} = (-1)^{i+j} \det(M_{ij})$.
3. Строится присоединенная матрица $A^* = C^T$.
4. Вычисляется обратная матрица $A^{-1} = \frac{1}{\det(A)} A^*$.
5. Решение вычисляется произведением $X = A^{-1} \cdot B$.

## 📂 Структура проекта

```text
determinant/
├── core.py       # Вычислительное ядро: алгоритмы решения СЛАУ, вычисление определителей, форматирование
├── app.py        # Графический интерфейс на Tkinter / ttk: формы ввода, валидация, скроллинг, вкладки
├── main.py       # Точка входа в приложение
└── README.md     # Документация проекта
```

### Назначение модулей:
* **[`core.py`](core.py)**:
  * `determinant_matrix(matrix)` — рекурсивное вычисление определителя через разложение по первой строке и миноры.
  * `solve_gauss(A, B)` — реализация метода Гаусса с протоколированием каждого шага.
  * `solve_cramer(A, B)` — реализация метода Крамера с выводом всех $\Delta_i$.
  * `solve_matrix(A, B)` — нахождение обратной матрицы и решение матричным способом.
  * `solve_slae_all(A, B)` — координатор: проверка условий применимости и запуск соответствующих методов.
  * `format_matrix`, `format_augmented_matrix`, `format_num` — красивое моноширинное форматирование чисел и таблиц.
* **[`app.py`](app.py)**:
  * Класс `App`, создающий интерактивное окно с панелью параметров, динамической таблицей ввода и вкладками результатов.
* **[`main.py`](main.py)**:
  * Инициализация объекта `tk.Tk()` и запуск главного цикла приложения (`mainloop`).

## 🚀 Установка и запуск

### Требования
* **Python 3.10** или выше.
* Модуль **Tkinter** (входит в стандартную поставку Python для Windows и macOS).

> В Linux (Ubuntu/Debian) при необходимости установите Tkinter командой:
> ```bash
> sudo apt-get install python3-tk
> ```

### Запуск
Склонируйте репозиторий или перейдите в папку с проектом и выполните:

```bash
python main.py
```

## 🖥 Использование приложения

1. **Задание размеров системы**:
   * Введите число уравнений ($m$) и число переменных ($n$).
   * Нажмите **«Создать сетку»**.
2. **Быстрые примеры**:
   * Для быстрого тестирования воспользуйтесь кнопками в блоке «Примеры»:
     * **3×3 (квадратная)** — классическая система с единственным целым решением ($x_1=1, x_2=2, x_3=3$).
     * **2×3 (прямоугольная)** — система с бесконечным множеством решений.
     * **3×3 ($\det = 0$)** — система с зависимыми строками.
3. **Ввод коэффициентов**:
   * Заполните ячейки матрицы $A$ и свободные члены $B$. Допускаются целые и дробные числа со знаком минус.
4. **Решение**:
   * Нажмите **«★ Решить СЛАУ всеми методами»**.
   * Вкладка **«Сводка»** покажет статус применимости методов и итоговый ответ.
   * На вкладках **«Метод Гаусса»**, **«Метод Крамера»** и **«Матричный метод»** можно изучить пошаговый ход решения. Текст на вкладках можно свободно выделять и копировать.
